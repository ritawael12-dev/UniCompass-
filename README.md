# 🌐 UniCompass 🧭

> **Your Ultimate Compass to a World of Opportunities!**

UniCompass is a modern, cozy, and minimalist web platform designed by students, for students. It aims to bridge the gap between global education dreams and reality by aggregating international scholarships and student living costs in one place.

---

## ✨ Features

* 🎓 **Scholarships Hub:** A direct, filtered database for fully funded global scholarships.
* 💰 **Living Costs Calculator:** Detailed, real-world statistics about rent, food, and student expenses abroad.
* 🤖 **AI CV Analyzer:** An upcoming smart tool to optimize student resumes to match international standards.

---

## 🎨 Design & Aesthetic

The project embraces a **Minimalist Luxury & Dopamine Decor** vibe:
* **Warm & Cozy Palette:** Creamy whites, earthy khakis, and soft cotton candy pinks.
* **User-Centric Layout:** Inspired by clean, premium Dribbble interfaces with fluid, rounded corners and interactive cards.
